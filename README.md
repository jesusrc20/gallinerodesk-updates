# GallineroDesk

Asistencia remota para Windows con conexión por código en la red local.

[Descargar instalador para Windows x64](https://github.com/jesusrc20/gallinerodesk-updates/releases/latest/download/GallineroDesk-Setup-x64.msi) · [Ver todos los paquetes](https://github.com/jesusrc20/gallinerodesk-updates/releases/latest)

1. Instala y abre GallineroDesk en las dos computadoras.
2. Comprueba que la PC remota indique **Disponible en esta red** y comparte su código de nueve dígitos.
3. En la otra PC escribe ese código y pulsa **Conectar**.
4. La persona de la PC remota acepta la solicitud.

No necesitas escribir IP o puerto ni iniciar sesión en GitHub. Los equipos deben estar en la misma subred con comunicación permitida. Puedes pausar el acceso y cerrar el programa para dejar de estar disponible.

Las actualizaciones se descargan automáticamente desde este canal público, sin cuentas. Windows 10 u 11 x64; el instalador incluye el runtime necesario. La conexión entre redes distintas por Internet no está habilitada por ahora.

Este repositorio contiene únicamente documentación y paquetes compilados. El código fuente de GallineroDesk permanece privado. Cada PC genera su propia identidad; no copies archivos de identidad de otra computadora.
